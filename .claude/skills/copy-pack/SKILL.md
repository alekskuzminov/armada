# Copy Pack

## Purpose

Используй этот skill, когда нужно подготовить тексты для:
- страницы услуги
- главной страницы
- первого экрана
- секции преимуществ
- блока процесса
- trust-блоков
- форм и CTA
- FAQ
- meta title / meta description

## Writing principles

- Пиши только на русском языке.
- Стиль: деловой, понятный, уверенный.
- Не используй банальные маркетинговые клише.
- Не используй агрессивный рекламный тон.
- Не обещай неподтверждённые результаты.
- Пиши так, как говорит сильная экспертная компания.
- Предпочитай ясность, а не украшательство.
- Любой тезис должен быть привязан к бизнес-смыслу блока.

## When to use

Используй skill при запросах:
- "напиши оффер"
- "нужны тексты на страницу"
- "сделай H1 + подзаголовок"
- "дай тезисы для блока преимуществ"
- "подготовь FAQ"
- "сделай пакет текстов для страницы услуги"
- "перепиши текст по-человечески, но по-деловому"

Используй этот skill, когда главное:
- сформулировать сильные и понятные тексты
- адаптировать тон и CTA
- подготовить контентный пакет для уже понятной структуры

Не используй этот skill для:
- проектирования структуры страницы с нуля
- генерации component scaffold
- переноса макета из Figma в код
- form integration
- финального релизного review
- полного SEO-аудита страницы

Если сначала нужно придумать структуру страницы, предпочитай `page-from-brief` или `service-page-generator`.

## Instructions

Если в проекте существует `.claude/company-context.md`, прочитай его перед началом работы над текстом.

1. Сначала определи:
   - тип страницы или блока
   - цель текста
   - целевую аудиторию
   - главный CTA
   - какие факты доступны
   - что нельзя обещать

2. Затем подбери формат:
   - H1
   - subtitle
   - short bullets
   - long-form paragraph
   - CTA
   - FAQ
   - microcopy
   - meta tags

3. Если фактуры мало:
   - не выдумывай детали
   - используй нейтральную формулировку
   - явно помечай, где нужен ввод от пользователя

4. Для SEO:
   - пиши естественно
   - не делай переспам
   - заголовки должны быть полезными, а не искусственно ключевыми

5. Для CTA:
   - используй понятные формулировки действия
   - избегай пустых формул вроде "Оставьте заявку прямо сейчас", если нет контекста

## Output format

Если пользователь не задал формат, выдавай:
1. Цель блока
2. Вариант H1
3. Подзаголовок
4. 3–6 тезисов
5. CTA
6. Дополнительный вариант в более сдержанном тоне
7. SEO title / description при необходимости

## Tone variants

При необходимости можешь давать 2 версии:
- более нейтральная корпоративная
- более сильная коммерческая

Но обе должны оставаться деловыми и без дешёвых рекламных конструкций.
