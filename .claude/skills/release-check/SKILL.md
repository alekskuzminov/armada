# Release Check

## Purpose

Используй этот skill перед завершением задачи, перед коммитом или перед релизом страницы.

## When to use

Используй skill, если задача звучит так:
- "проверь перед релизом"
- "сделай финальный review"
- "что ещё проверить перед публикацией"
- "готова ли страница"
- "собери release checklist"

Используй этот skill только на финальном этапе, когда основная реализация уже готова.

Не используй этот skill для:
- генерации новой структуры страницы
- написания текстов
- переноса макета в код
- form integration как основной задачи
- component scaffold
- SEO-аудита как отдельной узкой задачи
- частичной проверки одного аспекта вместо финального release gate

## Instructions

1. Сначала определи, что именно проверяется:
   - один компонент
   - одна страница
   - несколько секций
   - форма
   - весь поток задачи

2. Проверь минимум:
   - логичность структуры
   - консистентность UI
   - адаптив
   - heading hierarchy
   - accessibility basics
   - metadata
   - ссылки и кнопки
   - CTA-логика
   - success / error states для форм
   - текстовые несоответствия
   - obvious performance risks

3. Если задача кодовая, дополнительно проверь:
   - нет ли избыточных client components
   - нет ли ненужной сложности
   - не нарушены ли существующие паттерны проекта
   - понятны ли названия компонентов и props
   - были ли выполнены проверки типов, линта и сборки

4. Если задача контентная, дополнительно проверь:
   - нет ли повторов
   - нет ли пустых маркетинговых формулировок
   - соответствует ли текст задаче секции
   - есть ли понятное завершение и CTA

5. Замечания группируй по приоритету:
   - критично
   - нужно исправить
   - можно улучшить

6. Если всё хорошо, не пиши просто "всё ок".
   Дай короткий финальный checklist и обозначь остаточные риски.

## Output format

1. Статус готовности
2. Критично
3. Нужно исправить
4. Можно улучшить
5. Финальный checklist
6. Вердикт: можно ли выпускать

## Review style

- Будь конкретным
- Не переписывай всё без причины
- Не предлагай крупную переделку, если хватает локальных исправлений
