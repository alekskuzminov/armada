Провести SEO-аудит страницы по указанному пути.

## Аргумент
Путь к файлу страницы. Пример: `/seo-audit app/services/edm/page.tsx`.

## Алгоритм выполнения

1. **Прочитай файл страницы** из переданного пути.

2. **Прочитай правила проекта:**
   - Раздел "SEO и контент" из `CLAUDE.md`

3. **Применить skill `seo-page-audit`:**
   - Определить тип страницы и основной поисковый интент
   - Проверить: title, description, H1, иерархию H2/H3, наличие CTA, trust-блоки
   - Оценить соответствие контента интенту
   - Найти проблемы и точки усиления

4. **Выдать результат** в формате skill:
   - Общая оценка
   - Что хорошо
   - Критичные проблемы (critical)
   - Средние замечания (medium)
   - Быстрые улучшения (minor)
   - Рекомендуемый H1/H2 при необходимости
   - Вердикт: готовность к публикации
