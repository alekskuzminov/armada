Спроектировать структуру и создать каркас новой страницы по маршруту и описанию.

## Аргументы
Маршрут страницы и краткое описание через пробел.
Пример: `/page-scaffold services/laser-cutting "Страница услуги лазерной резки металла"`.

## Алгоритм выполнения

1. **Прочитай контекст:**
   - `CLAUDE.md` — архитектурные правила, паттерны проекта, маршруты
   - `.claude/company-context.md` — аудитория, голос бренда, CTA

2. **Применить skill `page-from-brief`:**
   - Определить тип страницы (услуга / раздел / landing)
   - Построить состав секций: первый экран, описание, преимущества, process, trust, CTA
   - Определить CTA-логику и proof-блоки
   - Предложить черновой H1 и H2

3. **Применить skill `component-scaffold`:**
   - Определить server/client split для каждой секции
   - Проверить, что можно переиспользовать: ContactFormBlock, Gallery, Breadcrumbs
   - Создать файловую структуру: `app/<маршрут>/page.tsx` + локальные компоненты

4. **Сообщи итог:**
   - Список создаваемых файлов
   - Каркас `page.tsx` с секциями-плейсхолдерами
   - Нужно ли добавить маршрут в `sitemap.ts`
   - Нужно ли добавить в `transparentHeaderRoutes`
   - Что потребуется заполнить на следующем шаге (тексты, изображения, данные)
